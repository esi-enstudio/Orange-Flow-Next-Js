--- Commands for Running the Project ---
From now on, you don't need to build the project repeatedly to run it. Remember the commands below:

  1. To start normally:
  If you want to start the bot (it will run in the background):
   1 docker-compose up -d

  2. To stop the bot:
  If you want to stop the bot:
   1 docker-compose stop

  3. To restart:
  If you make changes to the .env file or need to restart the bot:
   1 docker-compose restart bot

  4. To view logs (most useful):
  To check if the bot is working properly or if there are any errors:
   1 docker logs -f orange_flow_bot

  5. To stop and delete everything:
  If you want to stop and remove all containers:
   1 docker-compose down

  Tips:
   * Only use the --build flag if you make major code changes or add new libraries to requirements.txt:
     docker-compose up -d --build.
   * The advantage of using Docker is that even if your computer restarts (if Docker auto-starts), the bot will start again on its own (because restart: always is set).


1. Database Seeding: Your project has a file called seed_db.py. If the bot has no data or no user is authorized, you can seed the database. Command to run this from inside Docker:

   1    docker exec -it orange_flow_bot python seed_db.py
