Step 1: Git Branching Setup (One-time setup)
The best approach is to maintain two branches: main (for live code) and dev (for development).

1. Go to your OrangeFlow_Dev folder, open the terminal, and create the branch:
git checkout -b dev

2. Go to your OrangeFlow_Live folder and ensure you are on the main branch:
git checkout main



Step 2: Development Flow (Your daily work)
When you create a new module (e.g., Mela module), follow this sequence:

Working in OrangeFlow_Dev folder:
Once you finish writing new code and testing with the test bot, when everything looks good, save it in Git:

git add .
git commit -m "feat: added mela report module"
git push origin dev





Step 3: Code Merge (Moving from Dev to Main)
Now you need to bring your dev branch code into the main branch so the live folder can receive it. You can do this from the GitHub website (Pull Request) or via the command line:

While in OrangeFlow_Dev folder:

git checkout main        # Switch to main branch
git merge dev            # Merge dev branch work into main
git push origin main     # Push updated main branch to GitHub
git checkout dev         # Return to dev branch to start new work





Step 4: Updating the Live Folder (Deployment)
Now go to your OrangeFlow_Live folder and pull the new code:

In OrangeFlow_Live terminal:
git pull origin main

Restarting the bot:
Since you have added new modules or routers, you need to stop and restart the live bot:

python main.py





Database Table Update:
If you created new tables (e.g., Mela table), after running git pull in the live folder, when the bot runs for the first time, your code's await init_db() will automatically create the new tables in the live database. You don't need to do anything manually.


File Paths:
Always use relative paths when writing code (e.g., os.path.join("sessions", "file.json")). Do not write paths like C:\Users\... directly, because your PC path and the server path may differ.
